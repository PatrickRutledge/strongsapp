📖 Strong's Dictionary Text Analyzer - Desktop Application
================================================================

WHAT IS THIS?
This is a powerful desktop application for analyzing biblical text with Strong's numbers. 
It helps you discover word usage patterns, meanings, and original Hebrew/Greek definitions.

SYSTEM REQUIREMENTS
- Windows 10 or Windows 11
- No additional software required

INSTALLATION INSTRUCTIONS
1. Extract all files from the ZIP to a folder of your choice
   (Example: C:\Programs\Strong's Dictionary Analyzer\)

2. Double-click "Strong's Dictionary Analyzer.exe" to run the application

3. That's it! The app is ready to use.

HOW TO USE
- Text Analysis: Paste text containing Strong's numbers (like H7225, G3056) to analyze word patterns
- Single Lookup: Search individual Strong's numbers for quick reference
- Export Reports: Generate PDF reports of your analysis results

FEATURES
✓ Complete Hebrew and Greek Strong's dictionaries built-in
✓ Automatic word counting and frequency analysis
✓ Professional PDF report generation
✓ Clean, modern user interface
✓ Fully offline - no internet connection required

SUPPORT
This is a standalone application with no dependencies. If you encounter any issues:
- Make sure all files from the ZIP are in the same folder
- Try running as Administrator if Windows blocks the executable
- Check Windows Defender hasn't quarantined any files

UPDATES
To update to a newer version, simply replace the entire folder with the new version.
