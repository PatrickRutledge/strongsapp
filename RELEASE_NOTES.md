# Strong's LexiCount v1.1.0

## 🆕 What's New in 1.1.0

### 📚 Built-in KJV Bible Passage Selector
No more pasting Strong's-tagged text by hand. Pick a Book, Chapter, and verse range from the new dropdowns and click **Load Passage** — the complete KJV with Strong's numbers (all 66 books, 31,036 verses, ~350,000 tagged words) is bundled offline. KJV text and Strong's tagging supplied by [eBible.org](https://eBible.org/find/details.php?id=eng-kjv2006) (Public Domain).

### 🔤 Original English Word Preserved in Analysis
The analysis table and PDF export now include a new **Original Text** column showing the English word(s) from the source text alongside each Strong's entry. So when you analyze "God H430", you'll see "God" right next to the Hebrew lemma and definition — no more losing the context of which English word maps to which Strong's number.

### Other Improvements
- App identity finalized as "Strong's LexiCount" by Aether Forge
- Improved verse-range loading with auto-fill defaults
- Cleaner, more compact analysis pipeline

# Strong's Dictionary Analyzer v1.0.0

## 🎉 Initial Release - Desktop Application

A powerful cross-platform desktop application for analyzing Strong's Hebrew and Greek concordance data. Built with Vue.js and Electron, providing a beautiful, modern interface for biblical text analysis.

## ✨ Features

### Core Functionality
- **🌐 Web & Desktop Access** - Use online instantly or download for offline use
- **🔍 Interactive Strong's Dictionary Lookup** - Search and explore Hebrew and Greek words with their definitions
- **📝 Word Analysis Tools** - Analyze biblical text with automatic Strong's number identification
- **💻 Cross-Platform Desktop App** - Runs on Windows, macOS, and Linux
- **🎨 Beautiful Modern UI** - Clean, responsive design built with Vue.js
- **⚡ Fast Local Processing** - No internet connection required after installation (desktop version)

### Advanced Features
- **PDF Export** - Generate professional PDF reports of your analysis
- **Print Support** - Direct printing of analysis results
- **Comprehensive Database** - Complete Strong's Hebrew and Greek concordance data
- **Real-time Search** - Instant filtering and search capabilities
- **Keyboard Navigation** - Full keyboard support for efficient workflow

## 🚀 Installation

### 💻 Desktop App (Windows)
1. Download `Strong's-Dictionary-Analyzer-Windows.zip`
2. Extract the ZIP file to your desired location
3. Run `Strong's Dictionary Analyzer.exe`

### 🛠️ From Source
1. Clone this repository
2. Install dependencies: `npm install`
3. **Web version**: `npm run build` then serve the `dist` folder
4. **Desktop version**: `npm run electron`
